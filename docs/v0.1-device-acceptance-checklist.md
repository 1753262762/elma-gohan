# ELMA V0.1 真机验收 Checklist

## 验收准备

- [ ] 使用有效微信小程序 AppID，测试账号具备体验权限。
- [ ] 后端为当前 `contracts/openapi.yaml` 兼容版本；手机可访问 `VITE_API_BASE_URL`，不要使用手机自身的 `localhost`。
- [ ] 微信公众平台已配置 HTTPS request 合法域名及定位隐私声明；仓库和构建产物不包含敏感 Key。
- [ ] 使用 Node 22 执行 `pnpm dev:mp-weixin`，微信开发者工具导入 `dist/dev/mp-weixin`。

## 编译与权限

- [ ] 清除开发者工具缓存后重新编译，Console 无项目错误。
- [ ] `app.json` 的 `permission.scope.userLocation` 有明确用途说明，`requiredPrivateInfos` 仅包含 `getLocation`。
- [ ] 首次进入弹出前台定位授权；允许后显示“已获取当前位置”，可用时显示精度。
- [ ] 拒绝定位后显示拒绝状态；点击“去开启”可进入设置，重新授权后能够再次定位。

## 主流程

- [ ] 首页默认距离 1km、预算不限、品类 ANY；未定位时不能提交推荐。
- [ ] 中英文逗号输入可拆分、去空、去重；超过 10 项或单项超过 30 字时显示校验提示。
- [ ] 点击“帮我选”时按钮进入 Loading 且不能重复提交；请求携带持久化的 `X-Anonymous-User-Id`。
- [ ] 推荐成功只展示一家餐厅，名称、距离、人均缺省值、风险等级和服务端理由正确。
- [ ] 点击“换一家”只请求 reroll 接口；餐厅和剩余次数按响应更新，次数为 0 后按钮消失。
- [ ] 点击“就它了”能打开微信地图，名称、地址及 GCJ-02 坐标正确。
- [ ] LIKE、NORMAL、DISLIKE 分别用新推荐会话验证；提交成功后当前餐厅不能重复反馈，换店后可反馈新餐厅。

## 异常与恢复

- [ ] 断网、后端 5xx、POI 故障均显示可理解错误，页面保留重试入口且无重复请求。
- [ ] 校验错误和无推荐结果显示服务端提示；存在 `traceId` 时可用于排查。
- [ ] 推荐会话过期后清空状态并返回首页；结果页冷启动无状态时自动返回首页。
- [ ] 记录验收手机型号、微信版本、基础库版本、后端版本和失败步骤截图。
